# Global Partners LP

> Global Partners LP (NYSE: GLP) is an independent owner, supplier and operator of liquid energy
> terminals, fueling locations and retail experiences, headquartered in Waltham, Massachusetts. It
> distributes gasoline, distillates, residual oil, renewable fuels, crude oil and propane across the
> Northeast United States through an integrated network of terminals, gas stations and convenience stores.

Global Partners publishes no developer program, no API keys, no API documentation and no llms.txt of its
own (https://www.globalp.com/llms.txt returns 404 — this file was generated by API Evangelist from the
company's own live surface on 2026-09-12).

It does serve one real, fully public, unauthenticated machine-readable API: the WordPress REST API behind
its corporate site. Its custom content types model the company itself — terminals, retail locations, real
estate and the fuel/product taxonomies applied to them.

- Base URL: https://www.globalp.com/wp-json
- Route table (the whole contract): https://www.globalp.com/wp-json/
- Authentication: none for reads. Writes need a WordPress application password and return 401 to anyone else.
- Pagination: page + per_page (1-100), X-WP-Total / X-WP-TotalPages / Link headers.
- Errors: WordPress envelope {code, message, data:{status}} — not RFC 9457.
- Published rate limits: none. cache-control is max-age=600.

## Business data

- [Terminals](https://www.globalp.com/wp-json/wp/v2/sw_terminal): 157 liquid-energy terminals, tagged with state, product, terminal service and method of supply.
- [Retail locations](https://www.globalp.com/wp-json/wp/v2/sw_retail_location): 846 retail fuel and convenience sites, tagged with state, retail banner, fuel brand, fuel type and food options.
- [Real estate listings](https://www.globalp.com/wp-json/wp/v2/sw_property): properties marketed by the real-estate ventures business.
- [Leadership](https://www.globalp.com/wp-json/wp/v2/sw_employee): published leadership and employee profiles.

## What does not exist

- No OpenAPI, GraphQL, AsyncAPI, gRPC or SOAP contract published by Global Partners.
- No MCP server, hosted or local. No A2A agent card — /.well-known/agent-card.json and /.well-known/agent.json 404 or return HTML shells on every Global Partners host.
- No SDKs or client libraries on npm, PyPI or any other registry.
- No status page, no SLA, no changelog, no deprecation policy, no security.txt, no trust center, no bug bounty.
- No API pricing or plans. The surface above is served with no commercial terms attached.
